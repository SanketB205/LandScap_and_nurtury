# 🌿 Janai Landscape Services — Frontend Client

This is the React + Vite frontend for **Janai Landscape Services** (Pune, Maharashtra, India).

## 🚀 Key Client Modules
- **`src/pages/HOME/HomePage.jsx`**: Hero, interactive cost estimator preview, featured services, portfolio, plant highlights, and testimonials.
- **`src/pages/Services.jsx` & `ServiceDetails.jsx`**: 8 detailed services with live database slug routing.
- **`src/pages/Plants.jsx`**: Nursery catalog with live search, filters, care guide modal, and intelligent recommendation matchmaker.
- **`src/pages/SmartEstimator.jsx`**: Interactive garden dimensions, surface selection, irrigation choices, and dynamic cost breakdown.
- **`src/pages/Projects.jsx`**: Completed projects portfolio with Before / After comparison toggles.
- **`src/pages/QuoteRequestPage.jsx`**: Quotation request with automatic unique Reference ID generation (`JLS-INQ-XXXXX`).
- **`src/pages/Contact.jsx`**: Pune location details, Google Map embed, and contact form.
- **`src/pages/Auth/AuthPage.jsx`**: Login and Register portal.
- **`src/pages/Admin/*`**: Protected admin management suite (Overview, Inquiries, Services, Plants, Projects, Digital Quotations, Settings).

## 🛠️ Development & Build Commands
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build
npm run build
```
